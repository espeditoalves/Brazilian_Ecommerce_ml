# Bem-vindo à Documentação

Bem-vindo à documentação do projeto **Brazilian E-commerce ML**!

Este projeto consiste em pipelines de extração, análise, engenharia de atributos e modelagem de aprendizado de máquina para um conjunto de dados do e-commerce brasileiro (Olist).
